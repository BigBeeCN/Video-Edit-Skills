# 案例记录（不是通用配方）

本页只留一次口播制作的协作者回报，用来对照阶段记录该怎么写。不要把这里的钟点、跨度、人数或返工称呼写进 `../SKILL.md`、`pacing.md` 或别的项目，当成标准工时、提速比例或通用事实。

通用记法在 `process_gates.md`：墙钟跨度和计算耗时分开，不知道写未知，重跑次数没数过不要写成 0。

## 来源和状态

- 来源：协作者当天回报。未独立验证。
- 时区：北京时间。日历日期：未知。本页不补日期。
- 各阶段的主动处理耗时、计算耗时、等待、重跑次数：未知。
- 回报里的「交付」是交出成片的时刻，不是用户验收。
- 该次日志的文件修改时间后来已经变过。不能用现在的 mtime 倒推下面任何一个钟点或耗时。

## 不要从本案例提升成通用规则的内容

- 不把 3 小时 38 分或 2 小时 01 分写成交付时长承诺，也不写成提速前后的对比。没有提速实测。
- 嘴部开合、声纹若在该次项目里用过，方法和数值只留在当次项目记录。本页不转抄，也不写成阈值。通用流程只把它们当可选辅助；没有可用工具就写明，不能保证自动判断。
- 回报里出现过领读和后来的领读声替换。这只说明那次片里有这件事。通用要求是把画外领读和主人公复述分开，并逐句核对选入的人声。不从这一次推断识别方法已经可用。
