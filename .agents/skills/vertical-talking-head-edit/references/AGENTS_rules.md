# 硬规则（复制进项目根目录的 AGENTS.md，Codex 每次都会读）

> 只放不能违反的规则；流程和参数在 skill 里。若剪辑师本人给出新习惯，以他的为准并更新这里。已经标了「待确认」的，确认前按该条写的工作值，不要自行改回旧数字。

1. 原始素材只读，所有处理在副本上做。
2. 画面上的所有字只能用口播原话（身份标签除外，须标「非原话」）；每条带原话时间戳；用词前核对上下文。听不清的词剪掉，不猜。
3. 气口剪干净，吸气声和废话一点不留。唯一例外：爆点定格，放在自然静音里，≤0.4 秒，全片最多一处。
4. 字幕特效约每 2 秒一个（1.5 秒为密的上限），最长间隔 ≤3 秒；每条 3–4 个爆点，算进总密度；同一招全片只用一次。「待确认」另有一条：种类 18–22 种、每种最多 3 次。和本条的间隔、以及「只用一次」，在 30–50 秒片上个数对不齐。确认前不改本条的数字，也不改种类数。
5. 音效按 ≤0.4 个/秒执行（任意 4 秒最多 3 个，任意两个不同时响；预混的复合音效按 1 个计）。「待确认」0.4 不是用户的原话，是剪辑机器人在用户说音效太挤之后自己收的上限。剪辑师说过的标准是约 0.5 个/秒、均匀铺开。确认前按 0.4，不要为了凑 0.5 加音效。
6. 红色全片只用一次（高潮的章）。
7. 安全区优先：x 90–930、y 200–1540（1080×1920）；大字宽最多 85% 画宽；字不压脸、不压画面里的品牌标识；同屏不超过 3 层。
8. 卡点 ≤2 帧，从“字看得清的第一帧”量。
9. 响度 −14 LUFS（±1），真峰值 ≤ −1 dBTP。剪映没有总线限幅，导出的 mp4 要再测真峰值；超过 −1 dBTP 就在剪映里把总音量降大约 0.5 dB，再测。
10. 渲染前先把分镜表和重要程度表交用户确认；不写未核实的电话、地址；只用确认授权或自行合成的音乐和音效。
11. 质检报告只写亲自核实过的数据，量不到就写“没量到”。
