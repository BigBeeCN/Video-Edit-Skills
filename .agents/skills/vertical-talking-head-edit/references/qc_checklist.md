# 交付前质检（全部通过才交付）

| # | 项 | 方法 | 通过标准 |
|---|---|---|---|
| 1 | 拼图总览 | 按 6 fps 抽帧拼图逐张看；每个爆点段逐帧看 | 无出框、压脸、压品牌标识、错帧 |
| 2 | 安全区 | 渲染器逐帧量文字实际墨迹框（含描边、动画缩放；旋转元素如红章按旋转后的外框） | 越界 0；右边 ≤ x 930 |
| 3 | 原话 | 每条上屏文字对照 `src_t` 和上下文 | 100% 原话（身份标签除外） |
| 4 | 响度 | `ffmpeg -nostats -i out.mp4 -af ebur128=peak=true -f null -`。剪映导出的文件必须再测一遍，不能用 ffmpeg 合成的那条代替 | I = −14 ±1 LUFS，真峰值 ≤ −1 dBTP。剪映没有总线限幅；离线重混测到过 −0.7 dBTP。超了 −1 dBTP 就在剪映里把总音量降大约 0.5 dB，再导出复测 |
| 5 | 黑帧/冻帧 | `-vf "blackdetect=d=0.05:pix_th=0.05,freezedetect=n=0.003:d=0.2" -an -f null -`，再用 `d=0.1` 扫一遍。模糊或压暗的镜头上，每一条 freezedetect 命中都用相邻帧差再确认 | 无意外黑帧。帧差正好是 0 才是卡住的帧；大于 0 只是运动很小，不算冻帧。有意定格的时长看第 10 项。误报例子：19.5 秒一处 0.37 秒，是模糊后几乎不动的口播，帧差大于 0 |
| 6 | 规格 | ffprobe | H.264 High、1080×1920、30 fps、yuv420p、AAC 48 kHz、音画等长 |
| 7 | 卡点 | 从“看得清的第一帧”（不透明度 ≥0.5 或手绘线 ≥25%）量到关键词首字起音；入场动画按规则提前 1 帧开始，量时要算进去 | ≤2 帧 |
| 8 | 音效 | demucs `--two-stems=vocals` 分离后在伴奏轨测起音；重击看 30–150 Hz，pop/刷字看 3–12 kHz；对照 sfx_log | 大约 0.4 个/秒（v6 基准 0.387，43.9 秒 17 个）、相邻间隔大约 0.87–4.5 秒、任意 4 秒 ≤3 个、无同时叠响、与画面 ≤2 帧。0.5 个/秒只是上限参考，不是目标，不要为了凑到 0.5 加音效。重叠量不到的写“没量到” |
| 9 | 气口 | 每个剪点 10 ms 能量检查，按交付版本分别查。源时间用 `source_timerange.start`，不要用 `target_timerange.start` | 剪点两侧低于 −42 dBFS 的连续长度合计 ≤90 ms（已实测的标准）。字起音前 ≤67 ms：能量口径已通过（29/29，最大 40 ms，人声是降噪压缩后的单轨，没用 demucs）；试听确认没吞字头之前不改成默认。对比版句间 2–3 帧；唯一例外是定格 |
| 10 | 定格 | 分离人声逐帧 RMS + PyAV 逐帧帧差 | 选嘴最接近闭合的帧；帧差为 0 的区间与人声 < −45 dB 的区间完全重合；≤0.4 秒，最多一处 |
| 11 | 字在人后 | 遮挡比例 = 爆点帧上文字自身像素中落在蒙版 alpha > 0.5 处的比例；头发边缘放大 2 倍每 10 帧看一张 | 头挡字 25–30%；椅子等误抠物已从蒙版擦掉，白边止于肩部；无白边缺块；头部 alpha 相邻帧变化中位数 <0.1% |
| 12 | 爆点力度 | 对比 3–4 个爆点的字宽、推近、音效 | 力度分档，高潮最重；红章 30–40% 画宽；全片红色只出现一次 |
| 13 | 剪口复核 | 按分镜每段截音频重新 ASR | 无断字、无重复句 |
| 14 | 素材授权 | 核对音乐、音效、他人品牌 | 全部可用 |
| 15 | 时长统计表 | 对照成片量每段穿插画面、每个特效动画、四宫格的每一格；填 `timing_stats.csv`（列见 `spec_schema.md`）。最短值、平均值用明细重算一遍 | 每个穿插、每个特效动画都有实测时长；汇总行有最短值和平均值，且和明细一致。全屏空镜短于 1.6 秒不通过。口播跳切底线约 0.6 秒，不要用 1.6 秒去卡。四宫格整组短于 1.8 秒、单格短于 1.2 秒，不通过。定格不进这张表的镜头底线 |
| 16 | 重要程度分析表 | 对照 spec 和成片，填 `importance.csv`（列见 `spec_schema.md`） | 每个穿插镜头、每个字幕特效都有高/中/低，三条依据都写了；高的时长在该类型上限一侧，低的在下限一侧；处理写了删除的不在成片里 |

报告规则：每条结论带数字和单位（LUFS、dB、帧、px、秒）；自动看片工具的描述不能直接当结论，要自己抽帧核实。节奏按 `pacing.md` 的 v6 基准。安全区、原话、响度、卡点、气口、黑帧、音效不叠响，仍然全部通过才交付。音效大约 0.4 个/秒，不按 0.5 去凑。起音 ≤67 ms 的听感还没确认，写待试听，不要写成已经通过。

## 剪映导出后

走剪映路线时，上面各项打在剪辑师从剪映导出的成片上，不打在 Codex 生成的草稿上。不必读草稿。Codex 用现有的 ffmpeg 和 Python 质检直接跑这个 mp4。至少复查：卡点 ≤2 帧（第 7 项）、音效不叠响（第 8 项）、气口（第 9 项）、安全区（第 2 项）、响度 −14 LUFS 和真峰值 ≤ −1 dBTP（第 4 项）、黑帧或冻帧（第 5 项，模糊段用帧差确认）。第 15、16 项两张表照交。

草稿能不能打开，已经在剪映 11.7 上验证过一部分，见 `jianying_route.md`。在剪映里点导出还没测，待验证。导出文件没出来之前，保底成片仍按上面的清单质检。真峰值以导出的 mp4 为准；剪映没有总线限幅，ffmpeg 那条过了不能代替。
