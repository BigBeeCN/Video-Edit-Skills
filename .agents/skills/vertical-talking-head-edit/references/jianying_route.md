# 路线 A：剪映草稿（pyJianYingDraft）

> 整条路线要在剪辑师的 Windows 机器上跑通一次；跑通前交付一律附保底包（粗剪成片 + SRT + 分镜表）。

## 已核实（上游仓库 GuanYixuan/pyJianYingDraft）
- 最新版 0.3.1（2026-10-14）。`DraftFolder.create_draft` 可直接新建草稿；生成的草稿要在 Windows 版剪映里导出。
- 上游在剪映 10.8 上验证过新建草稿的本地素材、轨道、文本/花字/文本动画、滤镜、转场、关键帧、贴纸、蒙版、音频、导入 SRT。
- 字体：未缓存的字体要打开两次草稿才显示正确。特效/动画资源未缓存时，打开可能提示加载失败。
- 新草稿不在列表里：进出一个已有草稿，或重启剪映。
- 新版剪映的草稿通常是加密的（维护者在 issue #82 提到 8.2.0 编辑后和新建的草稿会加密），不写具体从哪个版本开始。读取已有草稿（模板模式）要自己传 `fallback_loader`，上游不提供解密，本 skill 不使用任何解密方案。所以默认只新建草稿，不改剪辑师已做的草稿。
- 自动导出只支持 Windows + 剪映 6 及以下；7 以上由剪辑师手动导出。导出要有对应权限，否则可能卡死。
- 曲线变速暂不支持。
- 草稿目录以剪映「全局设置」里的草稿位置为准，做成配置项，不写死。

## 待验证
- Windows 版剪映读 `draft_content.json` 还是 `draft_info.json`（上游写前者；有用户在 macOS 5.9 上要改名为后者）。以目标机器上实际草稿文件夹里的文件名为准。
- 常见的默认目录 `%LOCALAPPDATA%\JianyingPro\User Data\Projects\com.lveditor.draft` 只是第三方说法。
- ProRes 4444 透明层放进草稿后能否保留透明通道（默认不依赖它：爆点叠加层先在 ffmpeg 里合成好再导入，已在 Linux 跑通；PNG 序列导入为备选）。
- SRT 导入后时间是否对齐。

## 建议流程
1. 剪辑师在剪映里把 5–8 种常规特效各做一次，记下花字和动画名，填进 kw_class 的 `jianying` 字段（剪映样式库）。在能读模板之前，样式名由 Codex 写进新草稿，不复制他的草稿。
2. Codex 按 spec 新建草稿：口播剪段、整句字幕、音效与音乐时间点、B-roll、叠加层视频轨。
3. 爆点（字在人后、文字遮罩、数字滚动）走路线 B，在 ffmpeg 里合成好再导入；字在人后也可由剪辑师用剪映「智能抠像」，把人像复制一层盖在大字上，抠像前后擦掉误抠物。
4. 剪辑师打开草稿（字体不对就再开一次），检查后手动导出。
