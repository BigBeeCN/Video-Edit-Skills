# 口播占比、穿插时长、字幕特效节奏

流程在 `../SKILL.md`。这里只放数字。和旧数字打架的，文末「待确认」写明两边，确认前不要自行取一个。

v5、v6 两轮返工里验证过的做法按下面执行。片长仍是 30–50 秒。

## 口播和穿插

- 全屏口播 ≤ 全片 40%。v6 那条成片实际是 24%，40% 是上限，不是目标。
- 单段纯口播 ≤ 3 秒。情绪重的那一句可以放到约 3.3 秒，全片就这一处放宽。
- 「重要程度高可以更长」只加在穿插镜头上，不加在纯口播上。纯口播段再重要也不超过 3 秒（情绪句 3.3 秒）。
- 穿插形式轮换：全屏空镜、上下分屏、小窗口播、四宫格、变速。降口播占比靠分屏和小窗口播，不靠快切。同机位跳切可以留着接气口，不用它把占比打下去。
- 主题相近的短镜头合并成一段，宁少勿碎。四宫格、多格快切是设计好的一组，算一段，不是把同一主题切碎。

## 时长按类型和重要程度

每个穿插镜头、每个字幕特效先标重要程度（高 / 中 / 低），表的列在 `spec_schema.md`。三条依据都要写：

1. 是否直接撑起主题主线。
2. 是否对应关键词或转折点。
3. 是否带需要看清的信息。

类型基准：

| 类型 | 基准时长 |
|---|---|
| 大全景 / 运镜 | 2.5–4 秒 |
| 带信息的特写（动作要做完） | 约 2–3 秒 |
| 简单静态特写 | 1.5–2 秒 |
| 分屏 / 小窗口播 | 跟满整句台词 |
| 多格快切 | 每格 0.6–1 秒，整组 ≥ 2 秒 |

重要程度高：取该类型上限，可以再长。低：取下限。可有可无的删掉，时间让给重要镜头。

硬底线：任何镜头不能一闪而过。v6 最短的一条是 1.6 秒。和上表里短于 1.6 秒的数字怎么并存，见文末，确认前两边都留着。

变速：观感不快于 1.5 倍。这是播放速度，不是跳切那下 1.08 倍推拉（推拉是缩放）。

## 字幕特效节奏

下面这些旧规则里没有对应数字，按这里执行：

- 出场 ≥ 0.25 秒。入场 0.3–0.4 秒、缓动减速收尾，和旧的逐字 6–8 帧、爆点 4 帧推近、红章 3 帧砸下冲突，见文末。确认前不要改那些帧数。
- 关键词强调：完整停留 ≥ 0.8 秒。完整停留从字已经看得清开始算，不算入场。
- 大字、盖章、数字滚动：先蓄势，停稳之后 ≥ 1.2 秒。蓄势本身占多少帧，和旧的「3 帧砸下 / 4 帧推近」冲突，见文末。停留这段按 ≥ 1.2 秒留，不要因为入场帧数没定就把它省掉。
- 打字机：8–10 字/秒。
- 翻转、故障、甩镜一类转场：0.4–0.6 秒。
- 字幕可读时长按 4–5 字/秒估算。一行仍 ≤ 12 字，所以一行大约要 2.4–3 秒才读得完。不够就延长到下一句开始，但出点比这句说完再晚不超过 0.4 秒。语速过快、留不出这个时长时，对口型优先，不要为了读完把字拖过嘴型。
- 特效种类 18–22 种，挑最好看的；每种最多 3 次，不连续用同一种。重头戏 3–4 段（个数和原来的爆点 3–4 个一致），动画放慢，让观众看清。种类个数和旧的间隔规则对不上，见文末。
- 音效：工作值全片 ≤ 0.4 个/秒，任意 4 秒内最多 3 个。同一时刻画面上最多 3 层（这条和硬规则里的同屏不超过 3 层是同一条）。0.4 和剪辑师原话 0.5 的冲突见文末。任意两个音效间隔 ≥ 0.25 秒、不叠响，这两条旧规则没被新规则改掉，继续执行。复合重击音效按 1 个计。

卡点仍是 ≤ 2 帧，从字看得清的第一帧量到关键词首字起音。它管的是入点对齐。上面「比说话晚不超过 0.4 秒」管的是字幕出点。两个都要满足，不是同一件事。

## 待确认

确认前：写了工作值的，按工作值执行。没写工作值的，两边数字都保留。质检报告开头把这条标成「待确认」，不要改成通过，也不要改 spec 去消掉它。安全区、原话、响度、卡点、气口、黑帧这些仍然按各自的标准通过才交付。

1. 音效密度。剪辑师本人说过的标准是约 0.5 个/秒、均匀铺开，并且每 4 秒窗口 1–3 个（含下限 1 个）。新规则是 ≤ 0.4 个/秒，任意 4 秒最多 3 个，没写下限。**工作值用 0.4 个/秒，窗口只卡上限 3 个。** 不要为了凑回 0.5、也不要为了凑满每个窗口至少 1 个，去加音效。30 秒片大约差 3 个（15 对 12），50 秒片大约差 5 个（25 对 20）。0.4 个/秒比「4 秒最多 3 个」更紧（4 秒里平均 1.6 个）。

2. 常规档间隔对不上种类数。旧规则：每 1.5–2 秒一个，最长间隔 ≤ 3 秒；硬规则里还有「同一招全片只用一次」（`../SKILL.md` 里这句话点名的是字在人后、文字遮罩、全屏数字滚动加红章、竖排金句这几招）。新规则：种类 18–22 种，每种最多 3 次。个数大致是：

   | 片长 | 每 1.5 秒一个 | 每 2 秒一个 | 只保证间隔 ≤ 3 秒时最少 |
   |---|---|---|---|
   | 30 秒 | 约 20 | 约 15 | 约 10–11 |
   | 40 秒 | 约 27 | 约 20 | 约 14–15 |
   | 50 秒 | 约 33 | 约 25 | 约 17–18 |

   18–22 种、每种至少用 1 次，实例数就不能少于 18，也不能多于 66。30 秒、每 2 秒一个只有约 15 个，凑不满 18 种；每 1.5 秒一个约 20 个，盖得住 18–20 种，盖不住 22 种。50 秒、每 1.5–2 秒一个约 25–33 个，18–22 种都盖得住，而且用不满「每种 3 次」（33÷18≈1.8）。若这 25–33 个还要求每招只用一次，种类就会超过 22。所以两条在 30 秒的稀的那头、和 50 秒且「只用一次」的那头，不能同时成立。确认前不要改间隔，也不要改 18–22。

3. 入场有多快。旧数字在 30 fps 下是：逐字入场 6–8 帧 = 0.20–0.27 秒；爆点 4 帧内推近 = 0.13 秒；震屏 2–3 帧；红章 3 帧内砸下 = 0.10 秒。新规则：入场 0.3–0.4 秒，缓动减速收尾；出场 ≥ 0.25 秒；重头戏动画放慢。差一截（逐字入场大约少 2–6 帧，爆点推近大约只有新入场的三分之一）。确认前不要把帧数改成 0.3 秒，也不要删掉 0.3–0.4 秒。关键词停留 ≥ 0.8 秒、停稳后 ≥ 1.2 秒按上一节执行，这两条是停留，不是入场帧数。

4. 镜头最短 1.6 秒，对不上更短的类型下限。硬底线是不能一闪而过，v6 最短 1.6 秒。同一批新规则里还有：多格快切每格 0.6–1 秒（整组 ≥ 2 秒）；简单静态特写下限 1.5 秒，比 1.6 秒低 0.1 秒。分屏 / 小窗口要跟满整句，整句若短于 1.6 秒，跟满也会低于这条底线。确认前，时长表里这些短于 1.6 秒的格子、静态特写、短句分屏都单独标「待确认」，不要当成已经过线，也不要擅自垫长或删掉。

5. 定格 ≤ 0.4 秒（全片最多一处，只放在自然静音里）短于 1.6 秒的镜头底线。定格是停在静音上的一帧，不是穿插镜头。确认前定格仍按 ≤ 0.4 秒，不把它算进穿插底线，也不放宽到 1.6 秒。
