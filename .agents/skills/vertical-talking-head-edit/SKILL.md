# 竖屏实拍口播短视频剪辑（Windows + Codex + 剪映）

适用场景：手上只有别人拍好的素材（口播 + 空镜），要剪成 30–50 秒、1080×1920 的竖屏短视频，最后由剪辑师在剪映里收尾或直接出片。用户口头说 30–60 秒时，成片目标仍是 30–50 秒。

硬规则（不可违反）见 `references/AGENTS_rules.md`，开工前把它放进项目的 `AGENTS.md`。本文件只讲流程。`references/process_gates.md` 是这一轮流程修订草稿：说话人、预览、缓存、失效、阶段记录。它不替代 `references/pacing.md` 里已认可的 v6 节奏。案例钟点只在 `references/case_notes.md`，不当成标准工时。

状态词：已验证、待核验、待实现、建议、未知。缓存、自动失效、增量渲染、自动说话人判断都没有实现。标了待实现的，不要当成已有程序。

顺序：素材只读并做索引 → 转写校对 → 划定说话人、候选句和源片区间 → 选句、定稿、定剪点 → 低清口播粗剪 → 分镜和重要程度请用户确认 → 短字效样片 → 低清包装预览 → 高清输出 → 最终导出上的完整 QC。低清和说话人核对是内部检查。用户确认仍是渲染前这一轮，不把每次内部检查再加成审批。存疑人声没关掉，不得进入包装。

## 输入
- 素材目录（只读，绝不改动原件；先复制一份到工作目录）。
- 剪辑师本人的风格习惯（若有）。**剪辑师本人说过的习惯 = 硬标准；参考片只当招式库，学手法不学参数，冲突时听剪辑师。** 节奏数字以 v6 基准为准（B 大确认满意的成片，并同意按这个节奏量），见 `references/pacing.md`。这是对 v6 节奏的认可，不是交片即验收。起音 ≤67 ms 的听感仍待核验，不改成默认。项目里已经认可的风格模板继续沿用。本轮只把字效改成按内容选用，不把这次修订写成已经替代 v6 标准。
- 可选：参考片、品牌标识位置、片尾 CTA 文案（不得写未核实的电话/地址）。

## 输出
- `spec.json`（分镜，唯一剪辑依据）、成片 mp4、`.srt`、逐秒 QC 拼图、QC 报告。
- `speakers.csv`：说话人、候选句、源文件身份、源片区间、是否存疑。列见 `references/process_gates.md`。
- `importance.csv`：每个穿插镜头和每个字幕特效的重要程度。列见 `references/spec_schema.md`。
- `timing_stats.csv`：每段穿插画面和每个特效动画的时长，以及最短值、平均值。列见 `references/spec_schema.md`。
- `stage_log.csv`：每阶段的开始、结束、主动处理耗时、计算耗时、等待、重跑次数、返修原因。不知道写未知。列见 `references/process_gates.md`。这是记录，不是工时承诺。
- 剪映草稿：剪辑师用来自己改特效、空镜时长和变速的工程。做法和哪些已经在剪映 11.7 里打开确认过，见 `references/jianying_route.md`。剪映里点导出还没测，保底交付成片 + SRT + 分镜表，外加上面这些表。
- 交出成片不等于用户验收。新片最终用户验收没发生，就在报告里标待核验。

## 第 0 步：环境自检（不过不开工）
按 `references/windows_env.md` 跑自检：先找 PATH 里的 ffmpeg 和 Python。剪映自带的 ffmpeg 没有 zscale 和 libx264，不能算通过；用完整版（gyan.dev full build，或项目 `tools` 目录里的便携版）和 Python 3.10/3.11。还要有 faster-whisper + whisperX、Playwright + Chromium + 目标中文字体，可选 demucs / RVM。剪映草稿目录写入 `writable_roots` 后重启；没配的时候，沙箱写工作区外会直接拒绝，不弹批准。工作区如果是只读沙箱，写文件要 `require_escalated`。Codex 沙箱默认断网，模型和依赖要提前装好。任何一项失败，先报告缺什么，不要硬跑。各步骤的具体命令见 `references/windows_commands.md`。

## 第 1 步：素材盘点
1. 原件只读。处理只发生在副本上。
2. ffprobe 每个文件：分辨率、帧率（是否可变）、旋转、时长、色彩传输（HLG/PQ = HDR）。写成 `inventory.csv`。
3. 不导出 SDR 中间文件：每次读帧时在滤镜链里现转。所有素材都加 `fps=30`；HDR 素材的读帧滤镜链以 HDR 转 SDR 开头，否则画面发灰，截封面帧也一样（命令见 `references/windows_commands.md` 第 2 节）。
4. 每条素材抽缩略图打标签（内容、人物、可用时段、遮挡/黑场/起始偏暗、是否他人品牌）。标出**不能用**的素材和时段。
5. 素材索引以后可以缓存。缓存没有实现，标待实现。真做时键里要有源文件身份，不能只写某一台机器的绝对路径。见 `references/process_gates.md`。
- 检查：每条素材都有标签；原件没有被改写；传输特性为 arib-std-b67 或 smpte2084 的素材，读帧滤镜链都以 HDR 转换开头。

## 第 2 步：听写、说话人、候选句
1. faster-whisper 粗听：`medium` 模型、`device='cpu'`、`compute_type='int8'`、`language='zh'`、`vad_filter=True`、`word_timestamps=True`，`initial_prompt` 放行业词表。VAD 会漏句，再跑一遍关 VAD 的，这一遍加 `condition_on_previous_text=False`。
2. 先人工对照音频校对全文：专业词、数字、同音错字；Whisper 还会凭空编出没说过的句子，要删掉。**听不清的词直接从音频剪掉，不猜。**
3. 听写前固定先用 ffmpeg 抽 16 kHz 单声道 WAV 再交给 whisper。再把校对稿送进 whisperX 做强制对齐（结果写进 spec 的 `align` 字段），拿逐字起点（误差 0–3 帧）。whisperX 的字尾时间不可靠，出点用能量检测。
4. 校对之后、选句之前，把说话人、候选句、源文件身份、源片入出点写进 `speakers.csv`。摄影师画外领读和主人公复述必须分成不同说话人。
5. 声纹、嘴部开合只做可选辅助。本 skill 没有可用的自动说话人工具，不能保证自动判断。没有工具就在表里写「无可用工具，未做自动判断」。不把某一条成片的嘴部或声纹数值写成通用阈值。
6. 存疑项留在表里，回源片核对声音、连续嘴型和源片时间区间。闭唇辅音可以短暂闭嘴。单帧闭嘴不算换了人。
7. 转写缓存和说话人缓存都没有实现，标待实现。以后只有「已经人工校对、且没有未关闭存疑」的区间可以不重跑，其余和全部存疑区间都要再识别。缓存键必须同时有源文件身份和源片时间码。对不上就不得沿用。没有提速实测，不写提速比例。
- 检查：转写里没有未校对的专业词和数字；每句有逐字起点；选入成片的每句都有说话人、源文件身份和源片区间；领读和复述没有并成同一个人；将被 B-roll 完全盖住的选入句也有核对记录；`核对` 不是通过的句子不进入后面的分镜。

## 第 3 步：选句、定稿、剪点（先定叙事，再定特效）
选句只用 `speakers.csv` 里核对为通过、且存疑已关闭的句子。

1. 第 1 秒必须是钩子：「反差 + 结果」，用原话。片头不放空镜和 logo。
   - 钩子可以把两句不相邻的原话拼起来，但每半句都带 `src_t`，拼完不能改变原意。
   - 声音二选一，写进 spec：第一句照常开口、大字压在上面；或把结果句（≤3 秒）提到片头做冷开场，再回到正常顺序。
2. 删掉不推进故事的句子（口号、铺垫、重复表态），目标 30–50 秒。
3. 标出 3–4 个叙事转折点（开头钩子 / 场景转换 / 高潮结果 / 收束金句），爆点只放在这些位置；高潮力度排第一，开头次之。两个爆点至少隔 6 秒；约 30 秒的片子放 3 个，约 50 秒放 4 个。
4. 入出点用 10 ms 帧 RMS 能量检测（不用 Whisper 字尾）。气口剪干净：吸气声、废话一点不留。
   - 实际跑通的做法：先按能量裁，阈值 max(第 10 百分位 + 14 dB, −48 dBFS)，连续 3 个 10 ms 窗口有声才算开口，前留 0.10 s、后留 0.14 s，再人工收紧；检查剪点两侧低于 −42 dBFS 的连续长度合计 ≤90 ms。
   - 剪辑师习惯的目标：每个字起音前只留 1–2 帧（≤67 ms）。能量口径已在 Windows 上通过：按草稿的 `source_timerange.start` 量（不要用 `target_timerange`），29/29 ≤67 ms，最大 40 ms。量的是降噪压缩后的人声，没有 demucs。听感确认没吞字头、剪段重跑 ASR 无断字之前，不改成默认，仍用两侧静音合计 ≤90 ms。听感待核验。
   - 可另出一版句间留 2–3 帧的对比版给剪辑师挑。
5. 帧精确导出每段：`-ss` 放在 `-i` 前，`-vf` 含 `fps=30`，用 `-frames:v nf` 定长（nf = round((出点 − 入点) × 30)），`libx264 -preset veryfast -crf 12`，带 BT.709 三个色彩标记；音频按采样点拼接，每段 8 ms 淡入 / 15 ms 淡出防爆音。低清粗剪可以另出缩小版，剪点仍用这里定下的入出点。
6. 同机位跳切加 1.08 倍推拉；进出 B-roll 用甩镜 + 横向模糊。甩镜一类转场的时长见 `references/pacing.md`。1.08 倍是缩放，不是播放速度。
7. B-roll 只插在原话提到对应内容的地方，不为凑节奏硬插。
8. 口播和穿插按 `references/pacing.md`：压住全屏口播占比，单段纯口播有上限，情绪重的那一句可以略长。穿插在全屏空镜、上下分屏、小窗口播、四宫格、变速之间轮换。降口播占比靠分屏和小窗口播，不靠快切。主题相近的短镜头合并成一段，宁少勿碎。
9. 每条穿插先按类型定基准时长，再按重要程度取长或取短。1.6 秒只约束全屏空镜。口播跳切可以短到约 0.6 秒。变速观感有上限。数字在 `references/pacing.md`。

剪点、人声、口播替换或语速一旦再改，按 `references/process_gates.md` 让后面的字幕、字效、音效、B-roll、穿插时长和旧 QC 失效。

- 检查：每条上屏文字都能在转写里找到原话和时间戳，并核对上下文（同一个词在不同句里意思可能不同）。选入句的说话人核对是通过。

## 第 4 步：低清口播粗剪
用第 3 步的入出点做一条低清口播，分辨率低于 1080×1920，具体缩放由项目定。不把某一档分辨率写成已测速度。这一步不加花字、章和定格包装。

看三件事：说话人是不是表里那个人、连续嘴型和声音是否相符、剪口有没有吞字或留下废气口。将被 B-roll 完全盖住的选入句也要能听到，不因为成片里看不见嘴就跳过。单帧闭嘴不作为换人的结论。

没通过就回到第 2、3 步，不进入分镜确认，也不进入包装。这一步是内部检查，不单独请用户批。

低清粗剪不能代替后面的高清细节、综合响度和真峰值。

## 第 5 步：写分镜 spec.json，请用户确认
低清粗剪通过、且没有未关闭的存疑之后，再写分镜。字段规范见 `references/spec_schema.md`，关键词类别示例见 `references/kw_class.example.json`（示例里的词是某个项目的，换项目要重写）。口播占比、穿插形式、时长数字见 `references/pacing.md`。每段写清：源素材与入出点、版式、字幕、`kw_class`、特效预设、B-roll、音效、音乐段落、`src_t`（原话时间戳）。存疑未关闭的句子不写进 `segments`。

每个穿插镜头、每个字幕特效打重要程度（高 / 中 / 低）。看三件事：是否直接撑起主题主线；是否对应关键词或转折点；是否带需要看清的信息。高的把时长放到该类型上限甚至更长，低的放下限，可有可无的删掉，把时间让给重要镜头。这张表留成 `importance.csv`，列定义见 `references/spec_schema.md`。纯口播段不靠「重要」放到 3 秒以上，上限在 `references/pacing.md`。

**把分镜表和重要程度表发给用户确认。只此一轮。** 说话人核对、低清粗剪、短字效样片、低清包装预览都不另开用户审批。

## 第 6 步：字幕特效（两档）
**常规档**：大约每 1–1.3 秒一个，最长间隔约 2.7–3 秒。字效从效果库里按内容选，不凑满种类。v6 约 44 秒用过 22 种，那是那条成片的计数，不是必达，也不按「每 2 秒一种」或 18–22 种去凑。每种最多 3 次，不连续用同一种。稳定停留、安全区和上面的间隔不放宽，数字在 `references/pacing.md`。本轮这个选用方式是流程修订草稿，不替代已认可的 v6 节奏。已有认可的风格模板继续用。
- 底部字幕：白字黑描边，一行 ≤12 字，整句出现（是否给关键词上色做成参数，由剪辑师定）。淡入 2 帧，上移 10 帧，出场 0.12 秒。
- 强调放中层金色大字（关键词 1.75×，数字 2×），逐字入场 115%→100%，每字 11 帧，字间错开 2 帧；可加手绘下划线/圈注、纸纹、柔和投影。
- 可选招式：数字滚动、实物贴图配对应拟音、累加清单（字号 ≥ 底部字幕 1.2 倍，汇拢后再放大）、竖排对仗金句（出现时隐藏底部同句字幕）、开头身份标签（只在开头用一次，标注「非原话」）。

**爆点档**：每条 3–4 个，算进总密度，每一下叠满：
- 大字占画宽 75–85%（85% 是上限，安全区优先）；4 帧内推近 1.15–1.25；2–3 帧震屏带运动模糊；背景压暗 6–30%、适当去饱和（参数，以手机上看人像层次清楚为准），人物层不调色；预混好的复合重击音效（按 1 个计）。
- 力度分档：最重的一下推近 1.25、震屏 3 帧；其余推近 1.15、震屏 2 帧。
- 同一种最多 3 次，不要挨着再用同一种。v6 里字在人后、文字遮罩、计数器加红章、竖排各用了一次；金色大字、甩镜、手绘圈、画中画、高亮各用了 3 次。这是那条成片的用法，不是每一条都要做满的清单。
- 字在人后：字放肩线以上，避开手和道具；头要挡住字 25–30%（<15% 手机上看不出）；描白边前先把椅子等误抠物从蒙版里擦掉。
- 红章：全片唯一的红色，宽 30–40% 画宽，6 帧内 150%→100% 砸下。重击比砸下起点再晚 3 帧。计数器那下抖动 3 帧，其余爆点抖动 2 帧。
- 定格：只能放在一句说完后的自然静音里（人声 < −45 dB），选嘴最接近闭合的帧，≤0.4 秒（v6 钩子正好 0.400 秒，12 帧），全片最多一处，重击音效压在定格起点。这是「气口一点不留」的唯一例外。定格不是穿插镜头，不套全屏空镜的 1.6 秒。选这一帧是为了定格画面，不用单帧闭嘴判断说话人。完全重复的帧可以是这处有意定格。判据见 `references/qc_checklist.md` 第 5、10 项，不要看见帧差为 0 就当故障。
- 所有入场动画提前 1 帧开始。默认入场 11 帧，缓动减速。

节奏数字（入场帧数、打字机、停留、转场、字幕可读时长）在 `references/pacing.md`。打字机是打出约 0.11 秒/字、退格约 0.10 秒/字。关键词强调停留、大字 / 盖章 / 数字滚动停稳之后的停留、字幕按字数留可读时间（语速太快则对口型优先）、转场时长、同屏最多 3 层，也在那里。全片字效放在第 8 步的短样片通过之后。

## 第 7 步：声音
- 人声：高通 80 Hz → 降噪 → 轻 EQ → 压缩。
- 音乐：按章节换曲（剪辑师习惯），交叉淡化 300–600 ms；说话时侧链闪避。只用确认授权或自行合成的音乐。剪映里的音量关键帧仍待核验，见 `references/jianying_route.md`。
- 音效：大约 0.4 个/秒（v6 基准 0.387，43.9 秒 17 个）。相邻间隔大约 0.87–4.5 秒，任意 4 秒最多 3 个，不叠响。电平默认音效 RMS 比人声有声段低 14 dB（`db=-14`）；内容匹配的拟音优先于通用 pop。0.5 个/秒只是上限参考，不是目标，不要为了凑到 0.5 加音效。数字在 `references/pacing.md`。
- 响度：第一遍 `loudnorm=I=-14:TP=-1.5:LRA=11` 测量；第二遍代入测量值加 `linear=true`，后面固定接 `aresample=48000,alimiter=limit=0.7:attack=1:release=30:level=false`；最后 ebur128 复测，按 g = min(−14 − I, −2.9 − Peak) 补增益。短样例（例如 5 秒）走完两遍仍可能只有 −15.3 LUFS，不能拿来判断整片。`loudnorm` 的 `TP=-1.5` 是这条滤镜链用过的测量参数。交付目标是综合响度 −14 LUFS（±1）。真峰值 ≤ −1 dBTP 只是本项目的交付上限，可以按项目改，不是已核实的抖音官方要求。整片 ffmpeg 成片复测过 −14.0 LUFS、−3.4 dBTP，只说明那条限幅成片。剪映没有总线限幅。凡是降过总音量，都要对这一次最终导出重测综合响度（ebur128 的 I）和真峰值，不能凭大约降了 0.5 dB 算通过。见 `references/jianying_route.md`。

替换口播或改语速之后，相关字幕、字效、穿插时长和旧 QC 失效，按 `references/process_gates.md` 重检。

## 第 8 步：预览、高清渲染与交付
先做两级预览，通过后再高清输出。用现有 ffmpeg 和已有的 HTML/Playwright 字效路径，不新写渲染器。

1. 短字效样片：只渲染几秒，看字体、描边、入场。样片通过再铺全片字效。
2. 低清包装预览：分辨率低于 1080×1920，具体缩放由项目定，不把某一档分辨率写成已测速度。看字幕和关键词是否按 `references/pacing.md` 停稳、字是否压脸、是否进安全区、品牌和隐私是否处理过。停留和安全区不因为这是低清就放宽。
3. 低清预览不能代替最终高清成片上的细节，也不能代替综合响度和真峰值。这两项只在最终导出上测。

预览是内部检查，不额外请用户再批一次。第 5 步的分镜和重要程度确认仍然要有。

返修按 `references/process_gates.md`。改了声音、剪点、口播或语速之后，不能只重渲改过的几秒就宣布全片正确。局部预览只核改动段和接缝。最终整片导出后仍做完整 QC。自动缓存和增量渲染没有实现，不声称已经支持，也不写未实测的提速比例。

目标是一份剪辑师自己能改的剪映工程（特效、空镜时长、变速）。轨道怎么拆、哪些已经在剪映 11.7 里打开确认过，见 `references/jianying_route.md`。剪映里点导出还没测。导出没跑通之前，保底交付：成片 + SRT + 分镜表。

用 pyJianYingDraft 新建草稿（它不能读已有草稿；剪映自己的草稿是加密的，外面写的明文草稿复制进去仍是明文。加密影响读取，不影响生成）。只写 `draft_content.json`。素材用剪辑师这台机器上的绝对路径。口播主轨切成段；每条空镜单独一条轨道；字幕用剪映文本，关键词上色；BGM、每条音效、人声分开音轨。

花字、盖章、数字滚动、打字机做不进剪映原生特效。每条用 HTML/Canvas 单独渲染：Playwright 驱动 Chromium 逐帧截透明 PNG，视口 1080×1920、`device_scale_factor=1`、启动参数 `--font-render-hinting=none`，截图前等 `window.READY` 和 `document.fonts.ready`，`omit_background=True`；动画写成时间 t 的纯函数。进剪映的透明格式只有 ProRes 4444（`-alpha_bits 16`）或 PNG 序列，不要用 VP9 webm。解出来的像素格式是 `yuva444p12le` 也算通过。字已经做成剪映文本的，这条叠加只留图形，不要再渲染同一句字。手绘标记和剪映文字的对位要人看，这项待核验。剪辑师可以挪这些短片、改时长、改变速、删掉或换成剪映花字，改不了动画内部。ffmpeg drawtext 做不出逐字入场、字在人后。剪辑师若在草稿里改了时长、变速或换了口播，改之前的 QC 作废。

直接出成片时，再用 ffmpeg overlay 把这些层叠到口播上。
- 叠加前对底片做轻微调色 `eq=contrast=1.04:saturation=1.07`。
- 最终编码：`libx264 -profile:v high -preset slow -crf 17 -maxrate 16M -bufsize 24M -g 60 -r 30 -pix_fmt yuv420p -color_primaries bt709 -color_trc bt709 -colorspace bt709`，AAC 192k，`-movflags +faststart`。

仍待核验，本轮不写成已通过：起音 ≤67 ms 的听感；剪映里上下分屏和画中画 / 小窗口的位置；空镜拖动、替换、改变速；音乐闪避关键帧；在剪映里点导出以及导出成片上的 QC；手绘标记和剪映文字的对齐。写这些流程不必等上述项目测完。

质检打在最终导出的 mp4 上，不打在草稿上，也不打在低清预览上，也不必读草稿。Codex 用现有的 ffmpeg 和 Python 质检直接跑这个文件，综合响度和真峰值也在这个文件上重测。复查项见 `references/qc_checklist.md`。

## 第 9 步：质检（全部通过才把成片交出去）
逐项按 `references/qc_checklist.md`。包装前的说话人核对和低清检查不能代替这份清单。交付里要有 `timing_stats.csv`、`importance.csv`、`speakers.csv`、`stage_log.csv`。走剪映时，质检打在剪辑师导出的 mp4 上，不打在草稿上。报告只写自己抽帧、听音频核实过的东西，每条带数字和单位；量不到的写「没量到」，不硬报。起音 ≤67 ms 的听感还没确认，报告里写待核验，不要写成已经通过。

质检通过只表示可以交出去。交出去不等于用户验收。新片的最终用户验收标待核验，直到用户明确验收。B 大对 v6 节奏的满意只算那条成片，不自动算到新片上。

## 封面
- 分工：策划出文案和候选帧（写进 spec 的 `cover` 字段），剪辑出版式和导出（1080×1920 与 3:4）。
- 主标题用原话浓缩，可调语序（如「拧螺丝一个半月」），不加原话里没有的事实；≤7 字、最多 2 行。副标签放结果数字，贴纸 2–3 个。
- 标题和脸都放在中间 1080×1440（y 240–1680）里，抖音主页网格按 3:4 裁切。
- 每次至少给 3 个候选帧，附时间戳和理由，示意图标「非成稿」。
- 逐 0.5 秒扫全段找侧身或表情帧；视线方向决定版式（人看左上 → 人放右下、标题放左上）；衣服或背景有字时禁止镜像翻转。

## 成功标准
- 时长 30–50 秒，第 1 秒是原话钩子；上屏文字 100% 可追溯到原话。
- 选入人声逐句核对通过。画外领读和主人公复述分开。被 B-roll 盖住的选入句也听过。没有未关闭的存疑。
- 全屏口播占比、单段纯口播、穿插时长符合 `references/pacing.md`。全屏空镜不短于 1.6 秒；口播跳切可以短到约 0.6 秒。`timing_stats.csv` 里没有低于该类底线的。稳定停留和安全区不放宽。
- `importance.csv` 已交付：高的偏长，低的偏短，写了删除的不在成片里。
- 特效大约每 1–1.3 秒一个，最长间隔约 2.7–3 秒；种类按内容选，不凑满 22 种或 18–22 种；每种最多 3 次；爆点 3–4 个且力度分档。
- 音效大约 0.4 个/秒，间隔大约 0.87–4.5 秒，任意 4 秒最多 3 个，无同时叠响。0.5 个/秒只是上限参考，不是目标。卡点 ≤2 帧。综合响度 −14 LUFS ±1。真峰值 ≤ −1 dBTP 是本项目可配置上限，不是已核实的抖音官方要求。降过总音量的，最终导出重测了综合响度和真峰值。
- 安全区越界 0；无意外黑帧。freezedetect 和帧差只定位疑点，按 `references/qc_checklist.md` 第 5 项复核。字不压脸、不压品牌标识。
- `stage_log.csv` 已交。不知道的格子是未知，没有用墙钟跨度填计算耗时，没有把没数过的重跑写成 0。
- 用户确认过分镜表和重要程度表。最终导出上的完整 QC 通过。交出成片不等于用户验收；新片最终用户验收没有发生就标待核验。

## 常见坑 → 对策
| 坑 | 对策 |
|---|---|
| HLG 素材发灰 | zscale + tonemap=hable 转 SDR，gamma 约 1.12 |
| Whisper 字时间偏早、字尾拖进静音 | 起点用 whisperX 对齐，出点用能量检测 |
| VAD 漏句 | 再跑一遍关 VAD |
| 上屏字不是原话 / 上下文错用 | 每条带 `src_t`，QC 逐条对照转写 |
| 特效力度全一样，显得普通 | 分常规档和爆点档，爆点叠满 |
| 字在人后看不出 | 量遮挡比例，头挡住 25–30% |
| 椅子被抠进人像 | 字放肩线以上；描边前擦掉 |
| 卡点量错 | 从“看得清的第一帧”量；入场提前 1 帧 |
| 齿音被当成音效 | demucs 分离人声后只在伴奏轨上测 |
| 音效扎堆或为了凑密度加音效 | 大约 0.4 个/秒，间隔大约 0.87–4.5 秒，任意 4 秒最多 3 个。0.5 个/秒不是目标。复合音效按 1 个计 |
| 把 freezedetect 或帧差当成自动判决 | 两者只定位疑点。人物区和包装层分开看连续帧，对照源片、声音、设计意图。完全重复的帧可以是有意定格。模糊或低运动要复核，不自动给通过或故障 |
| 单帧闭嘴当成换了说话人 | 闭唇辅音可以短暂闭嘴。看连续嘴型、声音、源片时间区间。存疑留下回源核对 |
| 领读和复述混成同一个人 | 画外领读和主人公复述分开。选入人声逐句核对，包括被 B-roll 完全盖住的句子。存疑未关闭不包装 |
| 只重渲改过的几秒 | 声音、剪点、口播替换或语速一变，字幕、字效、音效、B-roll、穿插时长和旧 QC 都失效。局部预览看改动段和接缝。整片导出后仍做完整 QC |
| 低清预览当最终质检 | 低清只查说话人、口型、剪口、字幕停留、遮挡、安全区、品牌和隐私。高清细节、综合响度、真峰值以最终导出为准 |
| 为了凑满 22 种字效 | 字效按内容选。22 种是 v6 那条成片的计数，不是配额。间隔、停留、安全区仍按 pacing.md |
| 降了总音量就当响度通过 | −1 dBTP 是本项目可配置上限，不是已核实的抖音官方要求。对这一次最终导出重测综合响度和真峰值 |
| 用墙钟或 mtime 填计算耗时 | 墙钟跨度、主动处理、计算、等待分开记。不知道写未知。案例钟点见 `references/case_notes.md`，不能当成这次的实测 |
| 叠加用了 webm，剪映里全屏黑 | 只用 ProRes 4444 或 PNG 序列。查 webm 的 alpha 要用 `-c:v libvpx-vp9` |
| 剪映文本和叠加各有一句字 | 字已经在剪映文本里的，叠加只留图形。手绘标记的对位要人看，待核验 |
| 章或大字进抖音按钮区 | 右边界 ≤ x 930 |
| 边说话边定格、嘴型对不上 | 定格只放在静音里，≤0.4 秒。选接近闭嘴的帧只为画面，不用于判断说话人 |
| 动画滑入时扫过脸或出画 | 改为原位淡出 + 目标位放大淡入 |
| 查看工具按路径缓存旧图 | 每次检查图换新文件名 |
| 中文路径或空格导致命令失败 | 用 Python subprocess 传参数列表；文件读写显式 utf-8 |
| Whisper 幻觉出没说过的句子 | 对照音频人工校对全文后再对齐 |
| 特效层换一套没写进本 skill 的渲染 | 不要自行替换。花字、盖章、数字滚动、打字机只用 HTML/Canvas + Playwright，按条出带 alpha 的短片 |
| 靠快切把口播占比压下去，或全屏空镜一闪而过 | 占比和时长见 `references/pacing.md`。1.6 秒只约束全屏空镜。口播跳切可以短到约 0.6 秒。主题相近的短镜头合并 |
| 新草稿不在剪映列表里、字体不对 | 进出已有草稿或重启；草稿开两次 |
